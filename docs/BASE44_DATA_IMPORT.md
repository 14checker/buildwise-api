# Base44 Data Import

BuildWise exports four public-safe CSV files for Base44 bulk import:

- `products.csv`
- `retailer_offers.csv`
- `retailers.csv`
- `price_snapshots.csv`

These files are generated by `export_base44_tables.js` and shaped through `public_serializers.js`. Base44 should import these files only, not raw `db.json` or internal backend tables.

## Files

`products.csv` contains public product display fields for products that have at least one verified public-safe retailer offer.

`retailer_offers.csv` contains verified retailer links and display-safe retailer fields. It does not include affiliate URLs, source URLs, URL review notes, reviewer names, admin fields, scrape logs, user data, watchlists, alerts, or compliance logs.

`retailers.csv` contains public retailer reference fields: `retailer_id`, `name`, `domain`, and `active`.

`price_snapshots.csv` contains public price-history rows only after price data is verified. It may be header-only while BuildWise is still using seed/demo pricing.

## Why Prices May Be Blank

The current catalog still contains seed/demo pricing. Public exports keep verified retailer links visible but blank price-related offer fields until price data has a verified source/status.

Blank price fields are intentional. They prevent Base44 from showing synthetic prices as real production prices.

## Why Price History May Be Empty

Price history exports only when snapshots are connected to verified price data. Seed/demo snapshots are hidden by default, so `price_snapshots.csv` may contain only headers.

## Why Placeholder Offers Are Hidden

BuildWise hides offers with placeholder, search-page, wrong-domain, unverified, or low-confidence URLs. Public exports should only include retailer links that passed the URL verification gate.

## Regenerate CSV Exports

From the backend repo:

```powershell
node export_base44_tables.js
```

Safe defaults:

- No `WRITE=true` is required.
- CSV files are generated.
- `db.json` is not modified.
- Internal tables are blocked unless `INTERNAL_TABLES=true`.

Internal review flags exist but should stay off for production:

- `EXPORT_UNVERIFIED_OFFERS=true`
- `EXPORT_PRODUCTS_WITHOUT_VERIFIED_OFFERS=true`
- `EXPORT_UNVERIFIED_PRICES=true`
- `EXPORT_SEED_PRICE_DATA=true`

## Do Not Expose Publicly

Do not import or publish:

- raw `db.json`
- `affiliate_url`
- `source_url`, `scrape_url`, or `price_source_url`
- URL review notes or reviewer metadata
- users, watchlists, alerts, admin queues, scrape errors, source/compliance logs
- generated reports or temporary URL review files
